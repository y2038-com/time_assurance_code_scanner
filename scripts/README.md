# Scripts

Optional developer utilities for local experiments. The supported public interface
is the **`tacs`** CLI — see [QUICK_START.md](../QUICK_START.md).

| Script | Purpose |
|--------|---------|
| `example_usage.py` | Example `tacs`-oriented command illustrations |
| `run_env_wizard.py` | Thin wrapper around the environment-config wizard |
| `assign_catalog_rule_ids.py` | Maintenance: consolidate/assign packaged catalog `rule_id` values (not a runtime dependency) |

Other ad-hoc analysis scripts (if present in your checkout) are not part of the
supported public surface and may be incomplete or outdated.
